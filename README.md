# NDP2

Nesne Yönelimli Programlama 2 ödevi: .NET koleksiyon sınıflarının Türkçe adlarla yeniden yazımı (C#, .NET 8).

| Proje | Sınıf | Karşılığı |
|-------|-------|-----------|
| Proje1 | `DiziListe` (non-generik) | ArrayList |
| Proje2 | `Kuyruk` (non-generik) | Queue |
| Proje3 | `Yigin` (non-generik) | Stack |
| Proje4 | `HashTablo` (non-generik) | Hashtable |
| Proje5 | `SiraliListe` (non-generik) | SortedList |
| Proje6 | `Liste<T>` (generik) | List&lt;T&gt; |

Çalıştırma: `dotnet run --project Proje1` (ya da Visual Studio ile `NDP2.sln` açılır).
Her projenin `Program.cs` dosyası sınıfı deneyen bir örnek içerir.
